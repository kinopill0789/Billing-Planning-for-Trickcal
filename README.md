# トリッカル プレミアムショップ分析・比較サイト

『トリッカル もちもちほっぺ大作戦』の各ショップ（特別構成商品、エリーフショップ、月間パス、エリーフ商品など）で販売されているパックや商品のコストパフォーマンス、総獲得エリーフ換算を比較・計算するための非公式ファンツールです。

**公開サイト**: https://kinopill0789.github.io/Billing-Planning-for-Trickcal/

## 主な機能
- **全ショップ一括比較**: すべてのショップの商品をまとめて横断的に比較・ソート可能。
- **コスパ自動計算**: 1ガチャプル＝100エリーフの換算ロジックに基づき、価格あたりの価値を算出。
- **絞り込み・並び替え**: 有料・無料のコスト区分でのフィルター、アイテム名称での検索、コスパ・価格順のソートに対応。
- **初回2倍ボーナス対応**: エリーフ商品の初回購入2倍ボーナスを切り替えて計算可能。
